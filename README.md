# valenciawineries.org — preview copy

Static snapshot of https://valenciawineries.org (WordPress on Hostinger), used to try out changes before making them on the live site.

- Preview: https://vivekragavan.github.io/valenciawineries/
- Every page has `noindex,nofollow` so the preview stays out of search results.
- Re-crawl: `python3 tools/mirror.py <output-dir>` (rewrites links for the `/valenciawineries/` base path).
- Cart, checkout, forms and other server-side features don't work in a static copy.
